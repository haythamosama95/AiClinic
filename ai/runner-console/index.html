Routing selection

  1. Capability match — runner must declare required capabilities
  2. Health filter — prefer READY, deprioritize DEGRADED; exclude STARTING/UNREACHABLE
  3. Least-busy + round-robin tie-break among eligible runners

Lifecycle states: UNKNOWN → STARTING → READY / BUSY → DEGRADED → UNREACHABLE. When every runner is unreachable, gateway GET /ready returns 503 ai_no_capacity.

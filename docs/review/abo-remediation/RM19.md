# RM19 — Atomic void, release and suspension events

## Findings implemented

- **R6-DM3 (P1):** Reversal, held-release, and manual-void transitions now prepare their resulting state, ordered coverage-event snapshots, and signed receipt before value writes. Each action commits term/hot state, coverage-event outbox rows, any grant-void outbox row, and its replay receipt inside one synchronous SQLite transaction. Replays compare the original reversal payload or the operator operation binding and return the original receipt. Durable alarms are prearmed before commit and repaired on replay.
- **R6-DM5 (P2):** Suspend and resume now both emit `suspension_changed`; the alert metadata retains the requested operation, and the event snapshot carries the suspended flag. Repeated unchanged toggles do not emit another transition.
- No recipe steps were deferred. No migration was added. No precedence conflict was found.

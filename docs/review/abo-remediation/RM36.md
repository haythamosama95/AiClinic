## Discovered issues and known limitations

- R7-PS3 concurrency is tested sequentially only. The single-statement conditional `INSERT ... ON CONFLICT ... WHERE` is the guarantee; simultaneous calls are a known gap.
- A deleted installation's DO may gain empty tables on first read. This is an idempotent schema step with no domain rows.
- The payment history route now writes alert rows on a read path. This is the same pattern as `listOffers`.
- D1 batch size is up to 201 statements per page (limit 200). Verified green in CI.
- `coverage_mirror` can store state `none` if a `none` snapshot is applied. Admission denies it, so it fails closed.
- The Dart client must tolerate a null `plan_display_name`. It already does: `abo_client.dart` maps it to an empty string.

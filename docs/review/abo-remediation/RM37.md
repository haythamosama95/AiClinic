## Recipe step deviation (R2-C3 step 2, mint port)

The recipe asks the mint port (`frontend/lib/core/ai/supabase_aat_mint_port.dart`) to validate a
response version. `auth_internal.issue_ai_token` returns bare token text, which
`docs/architecture/ai-billing-orchestration/04-abo-contracts.md` §3.1 keeps by design. The token
carries its version in the `ver` claim (`'2'`, set in
`backend/supabase/migrations/20261014170600_r1_sql06_issue_ai_token_rate_limit.sql`).
Decision (plan §2.10 stop condition, resolved by a Sonnet decision agent): the mint port validates
`ver == '2'` from the token payload and throws `ContractVersionUnsupportedException` otherwise.
No backend change was made.

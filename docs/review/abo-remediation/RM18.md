## Findings implemented

RM18 is complete. The forward migration adds durable organization-level complimentary claims and accepted ceiling-policy commands. Runtime changes bind reservations to the original grant, envelope, signer, plan denominator and installation route; verify signed apply/no-effect receipts; and retain pending reservations until a verified terminal result. Policy versions are allocated and recorded atomically, with exact retry replay. The original-history backfill fails closed when retained evidence is insufficient.

The test-only auxiliary Durable Object drain is guarded by development/test-clock configuration. It initializes the DO schema under its normal lock, drains and verifies the outbox and alarm, and propagates errors. The ABO harness discovers optional installation rows independently and invokes the guarded auxiliary-worker control before storage cleanup. Both SQL migration splitters now handle `CASE ... END` inside triggers without prematurely terminating the trigger statement. A D1-only R4-A1 assertion no longer sets up unused platform state; its inserts and receipt-preservation assertion are unchanged.

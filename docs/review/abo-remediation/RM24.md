# RM24 — Fallback admission

## Findings implemented

- **R5-ADM1:** The fallback capacity check and insert now run in one conditional SQLite insert, so concurrent distinct keys cannot exceed the per-installation pending-weight cap. Same-key retries recover the original fallback identity and do not add weight.
- **R5-ADM3:** A fallback row stores its JTI and a unique `(installation_id, jti)` index prevents a second fallback admission for that JTI. The normal-admission-then-fallback exception remains bounded to one fallback row per JTI.
- **R5-A4:** Fallback admission carries the immutable mirrored term snapshot and cost ceiling through the guard. Completed and terminal outcomes persist `consumed` or `released`, journal usage against the fallback term, and write the replay envelope through the common settlement journal. A zero-charge terminal result records usage weight zero and leaves a released row that cron will not select.
- **R5-ADM2:** Routing receives the mirrored `max_cost_class`; legacy snapshots without a cost ceiling are treated as economy.

No recipe step was intentionally deferred within RM24. RM25 owns the separate A3 fallback charge/reconciliation path.

## RM25 seam, discovered issues, and operator actions

RM25 must add durable A3 charging for fallback work already marked `consumed`. The exact current seam is `ai-platform/src/credit/index.ts:reconcileGraceUsage`, which selects only `state = 'pending'` and calls `invokeSettleFallback`; `ai-platform/src/quota-do/index.ts:settleFallbackRPC` applies a weight to hot or ended-term usage without a durable settlement receipt. RM25 needs a consumed-row reconciliation interface keyed by the fallback request identity, an idempotent Durable Object receipt/state transition for the term-local charge, and a D1 usage-event write that cannot charge released rows or repeat a charge after a lost reply. The worker currently supplies the fallback `term_id`, `request_id`, `weight`, and consumed/released state needed at this seam. No RM25 charging behavior was added here.

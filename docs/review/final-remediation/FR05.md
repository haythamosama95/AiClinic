## Findings implemented
- FV-P3 (RM31 R9-CRON1 step 2, partial). FD-2 = detect. The minute cron now flags a scheduled period that was
  never attempted, after a 5-minute grace window. It does not start the work (the RM31 safety decision is unchanged).
  The alert clears through the existing success path. Nothing deferred.

## Changed files and symbols

  Rule: take the period containing now minus 5 min; flagged if last_succeeded_period differs, next_attempt_at is NULL and
  last_started_at is before the period start. Records last_error_code scheduled_period_missed once per period; the alert upsert is idempotent.

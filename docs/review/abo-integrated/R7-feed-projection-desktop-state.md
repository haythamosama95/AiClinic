**Fix steps:** (1) In `_AiPageState`, watch auth and key `_LiveVisitSummaryHost` by current user/org/role/visit, disposing old context before the new label. (2) Capture immutable inputs before composition awaits and retain mounted/generation guards; propagate the same identity through child host/dependencies and dispose old invocation state. (3) Guard host bootstrap/admin-summary commits by identity/generation and current administrator role; clear commercial fields on downgrade. Complete when A→B and late A responses can only produce B work under B, and role reload replaces affordances without automatic duplicate AI invocation. Coordinate T1/T2 repairs with this guard.
